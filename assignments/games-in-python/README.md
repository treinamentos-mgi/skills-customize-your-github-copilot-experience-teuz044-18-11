
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivo

Pratique manipulação de strings, loops, condicionais e seleção aleatória criando um jogo da forca em que o jogador tenta descobrir uma palavra oculta.

## 📝 Tarefas

### 🛠️ Preparar a Palavra e o Estado do Jogo

#### Descrição
Selecione uma palavra aleatória da lista predefinida e prepare as variáveis necessárias para acompanhar a partida.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra da lista de palavras fornecida.
- Inicializar o estado para registrar as letras adivinhadas e as tentativas incorretas.
- Definir o limite de tentativas incorretas permitido.

### 🛠️ Executar as Rodadas e Encerrar a Partida

#### Descrição
Peça palpites de letras ao jogador, atualize o progresso da palavra e encerre a partida quando houver vitória ou quando acabarem as tentativas.

#### Requisitos
O programa concluído deve:

- Solicitar palpites de letras ao jogador.
- Exibir as letras descobertas e indicar as posições ainda ocultas, por exemplo, `_ _ _`.
- Atualizar e exibir o número de tentativas incorretas restantes.
- Encerrar quando o jogador descobrir a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando vitória ou derrota.
